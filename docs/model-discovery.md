# Model discovery

## Supported sources and limits

| Harness     | Genuine catalog acquisition                                                                                                                            | Scope and limits                                                                                                                                                                                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code | Installed `claude --bare --print --input-format stream-json --output-format stream-json` initialization control response, `models[].value/displayName` | Unauthenticated first-party picker metadata, not account availability or effective managed/project policy. No prompt is sent. Existing app validation still omits unsupported IDs such as bracketed context suffixes, with a counted partial diagnostic. Aliases are preserved, never guessed or resolved. |
| Codex       | Installed `codex app-server`: `initialize`, `initialized`, paginated `model/list`, `data[].model/displayName`                                          | Unauthenticated first-party picker metadata from the installed harness, not the user's account catalog. No thread, turn, login, review or execution method is sent. Hidden models are excluded.                                                                                                            |
| Pi          | Existing fixed `models.json` declarations and documented offline `models-store.json`                                                                   | Unchanged static provider/model IDs and labels; cache may be stale. No Pi process, native module import, refresh, extension or credential resolution.                                                                                                                                                      |
| All         | Supported fixed global model setting plus app Main/Additional selections                                                                               | Retained configured/saved IDs, explicitly **not** catalog-only discovery. Custom values remain saveable regardless of membership.                                                                                                                                                                          |

Native metadata is deliberately credential-free. Only PATH is inherited. HOME, cwd, TMPDIR, CLAUDE_CONFIG_DIR and CODEX_HOME point to a new disposable directory, removed after process exit. No installed auth/config is copied or rewritten. Claude additionally disables settings sources, tools, slash commands, session persistence and ambient MCP; bare mode skips hooks, plugins, background prefetch and OAuth/keychain access. Codex uses empty configuration/auth storage with analytics and feedback disabled. This is metadata startup, not an agent/model job; native processes may create their own temporary files there.

Detected alternate providers or unsupported overrides do **not** fall back to the first-party catalog. Claude checks process/config environment for custom `ANTHROPIC_BASE_URL` and Bedrock/Vertex/Foundry selectors. Codex checks `model_provider`, `profile`, `model_catalog_json`, `openai_base_url` and process `OPENAI_BASE_URL`. Unreadable global configuration also suppresses native catalog acquisition. Profile/custom-provider catalog enumeration, account-specific availability and effective managed/project/environment policy resolution remain unavailable. Use retained IDs or Custom. No provider/harness is substituted, no example model names are hard-coded, and the Claude allowlist `availableModels` is not treated as a catalog.

Older/missing/incompatible installed CLIs report an unsupported/error `native-catalog` source, not a silently populated fake catalog. Each process has a 15-second deadline plus the existing 2-second termination grace, 5 MB protocol output, 2000 models and at most 20 continuation cursors. Repeated/malformed cursors, malformed/incomplete protocol, nonzero exit, timeout and output/model limits discard the entire catalog source, even after an earlier successful page. No stderr, account fields, commands, descriptions or other native output are returned. Only IDs/readable labels pass the existing validation/sanitization. Results are not persisted or server-cached.

Static roots reuse `nativeSettingsRoot`: `CLAUDE_CONFIG_DIR` or `$HOME/.claude`, `CODEX_HOME` or `$HOME/.codex`, `PI_CODING_AGENT_DIR` or `$HOME/.pi/agent`. Existing bounded trusted-file resolution, stable regular UTF-8 reads, credential-link rejection, 5 MB/file, 100 providers and 2000 models/source remain. Native metadata receives none of those user files. Maximum choices: Claude/Codex 2010, Pi 4010. Pi parsing, Save validation, native-default resolution and restricted execution policy are unchanged.

## Searchable selectors

`ModelSelect.tsx` remains shared by Main, Additional and Docker/Dangerous. Discover/Refresh is explicit-only, shared by harness but never by selected value. Opening shows all choices; subsequent typing searches ID/label. Null stays **Native default (resolved on Save)**; unsaved/saved custom IDs, duplicate reviewer entries, row identity and ordering are preserved. Discovery never Saves, inspects/sets up Docker, grants tools, enables polling or queues work.

Options label **Catalog** when they have a contributing `catalog` or `cached_catalog` source, otherwise **Configured/saved**; the summary gives both counts. Option descriptions carry the distinction for assistive technology. Configured/saved echoes alone cannot report successful Claude/Codex catalog acquisition. Source details explain the credential-free scope and unavailable capabilities. Loading, source errors, unsupported results, transport failures and Previous discovery remain distinct. No account-readiness claim is made.

Deterministic fixtures exercise the supported contract, not live provider or installed runtime readiness. See [public validation](publication-readiness.md).
